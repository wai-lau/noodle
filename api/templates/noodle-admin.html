noodle

end-to-end encrypted

https://wai-lau.net/noodle/<slug>?t=<token>#k=<K>

<K> is a secret key composed on your device

data after the # is not sent to the server

only people you send the full URL can access the poll

same scheme as excalidraw's end-to-end encryption

In plain words: your browser locks the poll with the secret <K> before anything leaves your device. The server only ever holds the locked copy and never sees <K>, so it can't read the names or the times. Only someone you hand the whole link to can unlock it — the part after the # carries the key.

Check the lock yourself: the sealing code is one short file, noodle-e2e.js (AES-256-GCM via the browser's built-in crypto.subtle). noodle has no build step, so the file the server runs is byte-for-byte the public one — one command confirms it.
